# Pressing the Mac Mini Power Button
This only applies to the Mac Minis that are in the video booth. This includes the Broadcast Sound and Media Minis. This should only be done if required, the computer should be put to sleep so if all is well should never need to press the button.

Here is a short video that shows how to press the button, the tool used in the video is stored behind the computer in the rack, you can access it from the side of the rack.
